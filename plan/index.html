Study one

The name

Does F1R3FLY, or F1R3, land with the people who will choose or buy the product. One name per respondent, assigned at random. Ten questions, two minutes: can they say it, spell it from hearing it, remember it tomorrow, guess what it is, and say it in a meeting without feeling silly.

Study two

The website narrative

Does f1r3fly.io say what the company does, and to whom. Part one is a ten-second look at the home page, then the standard first-impression questions. Part two is the live site for up to two minutes, then: what do they do, what do they offer, which industry, which words fit, how well it explained itself, what you'd do next.

How it runs

  1. Review. Greg and Nicholas read the questions and bias notes. Kill or change anything. A named research professional reads them once.
  2. Pilot, zero cost, this week. Five to eight people, mixed. Watch two of them do it live. Fix wording.
  3. Our own channels. Each channel gets its own link (the channel list) so results can be read by source and nobody can say the other side's sample cooked it.
  4. Paid wave if the pilot earns it. Prolific, about $200 for 200 screened developers, 40 per cell. That is where the numbers become decision-grade.
  5. Read it the way the scoring page says: developers 22 to 40 first, then everyone, then by channel.

What it does not settle

Trademark clearance, domain availability, search collision with Adobe Firefly and Firefly Aerospace, and how the name performs with a logo attached. Those are separate work. Research validates finalists; it does not pick the name. This study can rule a name out and put a number on the leetspeak spelling tax. It cannot tell us which name will build a brand, and we should say so before the results come in.

// Google Apps Script: appends every response as a row, one tab per study.
const TABS = { name: "name", site: "site", recall: "recall", decision: "decisions" };
function doPost(e) {
  const rec = JSON.parse(e.postData.contents);
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const tab = TABS[rec.study] || "other";
  let sh = ss.getSheetByName(tab); if (!sh) sh = ss.insertSheet(tab);
  const flat = flatten(rec), keys = Object.keys(flat);
  let header = sh.getLastRow() ? sh.getRange(1, 1, 1, sh.getLastColumn()).getValues()[0] : [];
  const missing = keys.filter(k => header.indexOf(k) < 0);
  if (missing.length) { header = header.concat(missing); sh.getRange(1, 1, 1, header.length).setValues([header]); }
  sh.appendRow(header.map(k => flat[k] === undefined ? "" : Array.isArray(flat[k]) ? flat[k].join("; ") : flat[k]));
  return ContentService.createTextOutput("ok");
}
function flatten(o, p, out) {
  out = out || {};
  for (const k in o) { const v = o[k], key = p ? p + "." + k : k;
    if (v && typeof v === "object" && !Array.isArray(v)) flatten(v, key, out); else out[key] = v; }
  return out;
}
// Optional: the next-day recall email. Add a daily time trigger on sendRecall.
function sendRecall() {
  const sh = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("name"); if (!sh) return;
  const rows = sh.getDataRange().getValues(), h = rows[0];
  const iEmail = h.indexOf("answers.email"), iRid = h.indexOf("rid"), iStart = h.indexOf("started");
  let iSent = h.indexOf("recallSent"); if (iSent < 0) { iSent = h.length; sh.getRange(1, iSent + 1).setValue("recallSent"); }
  const base = "https://hannahadamsdesign-spec.github.io/brand-study/name/recall/?r=";
  for (let r = 1; r < rows.length; r++) {
    const email = rows[r][iEmail], sent = rows[r][iSent];
    if (!email || sent) continue;
    if (Date.now() - new Date(rows[r][iStart]).getTime() < 20 * 3600 * 1000) continue;
    MailApp.sendEmail(email, "One question, ten seconds", "Yesterday you took a two-minute study about a company name. One question today: " + base + rows[r][iRid] + "\n\nThis is the only message you'll get. Your address is deleted within seven days.");
    sh.getRange(r + 1, iSent + 1).setValue(new Date().toISOString());
  }
}
